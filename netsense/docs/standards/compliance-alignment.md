# Compliance Alignment

NetSense is designed to align with common industrial and security standards.

## Standards

- **IEC 62443:** Role-based access, separation of monitoring and control, and secure deployment.
- **SNMP / LLDP:** Industry standards for monitoring and topology discovery.
- **Modbus TCP / OPC-UA:** Read-only OT protocol handling for safety.
- **AES-256-GCM:** Encryption standard used for PCAP storage.

## Security Controls

- Use least privilege for user roles.
- Encrypt forensic and audit data.
- Audit all senior-level access to PCAPs and incident sharing.
- Rotate keys and credentials regularly.
